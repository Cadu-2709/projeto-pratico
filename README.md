## Oque é versionamento semântico
O versionamento semântico é um sistema de numeração de versões que ajuda a transmitir claramente o tipo de mudança que foi feita em uma versão de software.

## Qual o significado de MAJOR.MINOR.PATCH
MAJOR: Mudanças incompatíveis na API. Ex: 1.0.0 -> 2.0.0- MINOR: Novas funcionalidades que são compatíveis com versões anteriores. Ex: 1.1.0 -> 1.2.0- PATCH: Correções de bugs compatíveis com versões anteriores. Ex: 1.1.1 -> 1.1

## Quando cada uma das partes deve ser incrementada
Major: Use quando algo que funcionava antes deixa de funcionar ou precisa ser alterado por quem usa sua aplicação/API.
Minor:Você adicionou algo novo, mas não quebrou o que já existia.
Patch:Você corrigiu algo que estava errado, sem mudar significativamente a funcionalidade.
